## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or pnpm

### 1. Install dependencies

```bash
npm install
# also install the typography plugin:
npm install -D @tailwindcss/typography
```

### 2. Run locally

```bash
npm run dev
```

Open [http://localhost:4321](http://localhost:4321)

### 3. Build for production

```bash
npm run build
```

Output goes to `dist/` folder.

## ✍️ How to Add New Articles

**Every article is a Markdown file in `/src/content/guides/`.**

### Step 1: Create the file

```
src/content/guides/my-new-guide.md
```

The filename becomes the URL slug:
- `my-new-guide.md` → `/guides/my-new-guide`

### Step 2: Add frontmatter

```markdown
---
title: "Your Guide Title – With Keywords for SEO"
description: "A 140-160 character description for Google snippets. Include the game name and key topics."
category: "beginner"        # beginner | survival | ships | multiplayer | settings | resources
publishDate: "2024-06-01"
updatedDate: "2024-06-15"   # optional
featured: false              # true = shows on homepage featured section
image: "/images/my-guide.jpg"  # optional, for OG tags
tags: ["beginner", "tips", "controls"]
author: "Windrose Team"
readTime: "5 min read"
---

## Your First Heading

Write your content here in Markdown...
```

### Step 3: Write your content

Use standard Markdown:
- `##` headings auto-appear in the Table of Contents
- Tables are supported and styled
- Blockquotes (`> text`) are styled as tips
- Inline `code` is styled automatically

That's it — the page is live after rebuild.

## 🌐 Deploy to Cloudflare Pages

Cloudflare Pages is free and perfect for this Astro site.

### Step 1: Push to GitHub

```bash
git init
git add .
git commit -m "initial commit"
git remote add origin https://github.com/yourname/windrose-guides.git
git push -u origin main
```

### Step 2: Connect to Cloudflare Pages

1. Go to [pages.cloudflare.com](https://pages.cloudflare.com)
2. Click **Create a project** → **Connect to Git**
3. Select your repository
4. Configure:
   - **Framework preset**: Astro
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
5. Click **Save and Deploy**

Every `git push` to `main` auto-deploys.

### Step 3: Add your domain

In Cloudflare Pages → Custom Domains → Add `windroseguides.com`

Update `astro.config.mjs`:
```js
site: 'https://windroseguides.com',
```

## 💰 Adding Google AdSense

When you're approved for AdSense, add ad units in two places:

**1. Article sidebar** (`src/layouts/ArticleLayout.astro`):
```html
<!-- Replace the placeholder div with: -->
<ins class="adsbygoogle"
     style="display:block"
     data-ad-client="ca-pub-XXXXXXXXXXXXXXXX"
     data-ad-slot="XXXXXXXXXX"
     data-ad-format="auto">
</ins>
```

**2. AdSense script** (in `BaseLayout.astro` `<head>`):
```html
<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-XXXXXXXXXXXXXXXX"></script>
```

## 🔧 Customization

### Change site URL
Edit `astro.config.mjs`:
```js
site: 'https://yoursite.com',
```

### Change brand color
Edit `tailwind.config.mjs` → `colors.brand` values.

### Add a new category
1. Add to the enum in `src/content/config.ts`
2. Add metadata in `src/pages/category/[category].astro`
3. Add the static path in `getStaticPaths()`
4. Add to Navigation and Footer links
