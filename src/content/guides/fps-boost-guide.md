## Why FPS Matters in Windrose

Sea combat in Windrose is fast-paced. Low FPS means sluggish cannon aim, delayed inputs, and — most importantly — losing fights you should win. This guide gets you to a stable **60+ FPS** on most hardware.

## Recommended Settings By PC Tier

### Low-End PC (targeting 60 FPS)
*CPU: i5-8400 or equivalent | GPU: GTX 1060 or equivalent | RAM: 8GB*

| Setting | Value |
|---------|-------|
| Resolution | 1080p |
| Display Mode | Fullscreen |
| Render Scale | 80% |
| Texture Quality | Medium |
| Shadow Quality | Low |
| Water Detail | Low |
| Foliage | Off |
| Anti-Aliasing | FXAA |
| V-Sync | Off |
| Motion Blur | Off |

## Settings That Kill FPS (Always Turn These Off)

Regardless of your PC tier, always disable:

- **Motion Blur** – zero gameplay benefit, heavy GPU cost
- **Ambient Occlusion** – subtle visual effect, significant performance hit
- **V-Sync** – adds input lag, cap FPS with Riva Tuner instead
- **Chromatic Aberration** – purely cosmetic, no reason to keep enabled
- **Film Grain** – same as above

## Windows Optimization Tips

Before tweaking in-game settings, make sure Windows is configured for gaming:

1. **Power Plan** → Set to "High Performance" in Windows power settings
2. **Game Mode** → Enable in Windows Settings → Gaming
3. **Hardware-Accelerated GPU Scheduling (HAGS)** → Enable in Display Settings (Windows 11)
4. **Close background apps** → Discord, Chrome, and Spotify all eat RAM
5. **Update GPU drivers** – always use the latest WHQL driver

## Checking Your Current FPS

Press `F3` in-game to open the performance overlay. It shows:
- Current FPS
- Frame time (aim for under 16ms for 60 FPS)
- GPU/CPU usage

If your GPU is below 90% usage but FPS is low, it's likely **CPU bottlenecked**.

## FAQ

**Q: What FPS does Windrose target?**  
A: The game targets 60 FPS on recommended specs, but most PCs can hit 100+ with proper settings.

**Q: Does reducing resolution help a lot?**  
A: Yes — dropping from 1080p to 900p can add 20–30 FPS on low-end GPUs.

**Q: My FPS drops near islands. Is that normal?**  
A: Yes. Island areas have more foliage and NPCs. Set Foliage to Low if island FPS is an issue.
