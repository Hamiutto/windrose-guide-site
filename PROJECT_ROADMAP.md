# Windrose Guides Project Roadmap

> Last Updated: 2026-07-02

## Project Goal

Build a high-quality SEO/GEO optimized game guide website for Windrose.

Long-term goals:

- Rank on Google Search
- Be cited by ChatGPT, Gemini, and Perplexity
- Generate organic traffic
- Monetize through AdSense, affiliate marketing, and digital products
- Create a reusable template for future game guide websites
